**UNNU TTS** is a lightweight, C++-based text‑to‑speech engine built on top of **Piper**, extended with **multi‑speaker support**, **emotion overlays**, and optional **robotic voice effects**. It is designed for developers who want fast, local, production‑ready speech synthesis with flexible voice control and minimal runtime dependencies.

### Key Features
- **Piper‑based TTS core** — efficient, high‑quality, on‑device speech synthesis.  
- **Multi‑speaker support** — dynamically select voices or switch speakers at runtime.  
- **Emotion overlay system** — apply emotional tone (e.g., happy, sad, angry) on top of base voices.  
- **Robotic voice mode** — optional DSP layer for synthetic/robotic effects.  
- **Simple C++ API** — clean headers under `include/unnu_tts` for easy integration.  
- **CMake‑friendly build** — integrates smoothly into existing C++ projects.  
- **Minimal dependencies** — optimized for local, offline use.
